# The Hand That Lets Go

A short poem about agency — the power to choose and to act, and what happens when a person lends that power to an agent and takes the blame for what it does.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.txt` to the output directory.
